# 品牌餐具設計

外帶包材與內用餐具的設計規劃，最終產出交由廠商打樣、製作。

## 設計方向

| 項目     | 內容                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 品牌調性 | 簡約、溫潤、日系咖啡店氛圍                                             |
| 主色     | （待定，填 Pantone 色號，例：Pantone 7527 C 米灰）                     |
| 輔色     | （待定，填 Pantone 色號）                                              |
| Logo     | 單色印刷優先（降低印刷成本），置於杯身正面置中或右下角                 |
| 字體     | （待定，中文／英文字體名稱，需確認商用授權）                           |
| 材質偏好 | 外帶以紙材、可分解材質為主；內用以陶瓷、玻璃、木質為主                 |
| 一致性   | 外帶與內用共用同一套視覺元素（Logo、色帶、圖紋），僅依材質調整呈現方式 |

## 外包製作流程

1. **完稿準備** → 產出：Logo 向量檔（AI／PDF）、色彩規範（Pantone 色號）、各品項印刷位置示意圖
2. **詢價** → 提供品項規格表（本文件）向 2–3 家廠商索取報價與 MOQ
3. **打樣** → 每品項至少打樣 1 次，確認顏色、材質、尺寸後才下正式訂單
4. **首批下單** → 依上表數量下單，確認交期（一般客製紙杯約 3–4 週）
5. **驗收** → 核對印刷色差、數量、瑕疵率

### 給廠商的檔案清單

- [ ] Logo 向量檔（AI 或 PDF，文字轉外框）
- [ ] Pantone 色號與印刷色樣
- [ ] 各品項刀模圖（紙盒、提袋類，通常由廠商提供模板回填設計）
- [ ] 印刷位置與尺寸標註圖

### 候選廠商類型

| 類型           | 適用品項                   | 備註                                |
| -------------- | -------------------------- | ----------------------------------- |
| 紙杯／紙容器廠 | 熱飲杯、冷飲杯、紙盒、提袋 | 注意 MOQ，通常單品項 1,000–3,000 起 |
| 貼紙印刷廠     | 封口貼紙                   | MOQ 低，適合首批搭配素面包材使用    |
| 陶瓷客製廠     | 內用杯盤                   | 釉下彩耐用；打樣期較長（4–6 週）    |
| 雷雕加工廠     | 不鏽鋼餐具、木托盤         | 可少量代工                          |
