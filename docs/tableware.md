# 品牌餐具設計

外帶包材與內用餐具的設計規劃，最終產出交由廠商打樣、製作。

## 設計方向

| 項目     | 內容                                                                                                                             |
| -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 品牌調性 | 簡約、溫潤、日系咖啡店氛圍                                                                                                       |
| 主色     | 藍灰 #607A87（C62 M36 Y31 K25），見[品牌配色](brand/README.md#配色)；Pantone 色號待印刷廠對色                                    |
| 輔色     | 奶泡白 #FAF7F1、拿鐵琥珀 #CE9C61；Pantone 色號待印刷廠對色                                                                       |
| Logo     | 單色印刷優先（降低印刷成本），置於杯身正面置中或右下角；版本、尺寸與留白見[品牌使用規範](brand/README.md#使用規範)，單色版待製作 |
| 字體     | Noto Sans TC（思源黑體，SIL OFL 1.1 可商用），見[品牌字體](brand/README.md#字體)                                                 |
| 材質偏好 | 外帶以紙材、可分解材質為主；內用以陶瓷、玻璃、木質為主                                                                           |
| 一致性   | 外帶包材共用同一套視覺元素（Logo、色帶、圖紋），僅依材質調整呈現方式；內用餐具不印 Logo，選現成批發品                            |

## 外包製作流程

1. **完稿準備** → 產出：Logo 向量檔（AI／PDF）、色彩規範（Pantone 色號）、各品項印刷位置示意圖
2. **詢價** → 提供品項規格表（本文件）向 2–3 家廠商索取報價與 MOQ
3. **打樣** → 每品項至少打樣 1 次，確認顏色、材質、尺寸後才下正式訂單
4. **首批下單** → 依上表數量下單，確認交期（一般客製紙杯約 3–4 週）
5. **驗收** → 核對印刷色差、數量、瑕疵率

### 給廠商的檔案清單

- [x] Logo 向量檔（AI 或 PDF，文字轉外框）：[品牌](brand/README.md#logo)的 logo.pdf；單色版待製作

- [ ] 印刷位置與尺寸標註圖
