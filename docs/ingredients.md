## 備註

- 牛奶：70 元是先前向光泉牧場打探到的價格，不是正式報價。
- 優格菌：做優格與希臘優格用，1 包（1g）約可做 500ml 優格，室溫發酵，不適用優格機；360 元是單盒售價，3 盒以上有量購價。收到後冷凍保存。
- 水：以 `costs.md` 台水最高級距 12.075 元/度（1 度 = 1000L）計，四捨五入到 2 位小數，不含基本費。
- 紅醬：價格與內容量是一鍋的總成本與估算成品量；材料漲價時要手動更新，做好一鍋要手動入庫。
- 白醬、優格、希臘優格：同紅醬，價格與內容量是一鍋的總成本與估算成品量。
- 蛤蠣：海鮮價格隨季節浮動，199 元是主婦聯盟的牌價，進貨時以實際價格更新。
- 白酒：依菸酒管理法不能網路下單，要打電話（07-554-6820）或到高雄門市購買；查價時網站顯示缺貨。
- 奶油、麵粉：目前是網路零售價，開店前改找烘焙材料行報價。

## 對應資料庫

| 文件欄位 | 資料庫欄位                                     | 說明                                   |
| -------- | ---------------------------------------------- | -------------------------------------- |
| 食材名稱 | `name`                                         | 食譜用這個名稱對應食材，必須一字不差   |
| 品牌     | `brand`、`url`                                 | 連結存到 `url`                         |
| 供應商   | `supplierId`                                   | 自製不填                               |
| 價格     | `price`                                        | 一個包裝的價錢，一項食材只有一組       |
| 內容量   | `eligibleQuantity`、`eligibleQuantityUnitCode` | `g` GRM、`kg` KGM、`ml` MLT、`L` LTR   |
| 單位成本 | `unitCode`                                     | 只取單位當基準單位，金額由後端依價格算 |
