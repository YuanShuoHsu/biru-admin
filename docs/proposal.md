## 四、功能規劃

Biru 由三個部分組成：顧客使用的點餐網站、門市與總部使用的管理後台，以及兩者共用的後端服務。以下依使用對象分成三類，並標示目前進度：

- **已完成**：功能已開發完成。
- **開發中**：規格已確認，正在開發，附上對應的開發項目。

### （一）顧客端

| 功能           | 說明                                                                                      | 狀態                                                               |
| -------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 線上點餐       | 提供內用、櫃檯、得來速與預約自取四種點餐方式；內用、櫃檯與得來速須掃描店內 QR code 點餐。 | 已完成                                                             |
| 線上付款       | 串接綠界科技金流，支援線上付款與退款。                                                    | 已完成                                                             |
| 電子發票       | 付款後自動開立電子發票，支援發票捐贈與統一編號查詢。                                      | 已完成                                                             |
| 優惠券         | 領取並於結帳時使用優惠券。                                                                | 已完成                                                             |
| 會員點數       | 消費累積點數，可兌換優惠券。                                                              | 已完成                                                             |
| 現場候位       | 取號並即時查看候位進度。                                                                  | 已完成                                                             |
| 多語系         | 介面支援繁體中文、簡體中文、英文、日文、韓文。                                            | 已完成                                                             |
| 候位限現場取號 | 須掃描門市入口 QR code 才能取號，並新增前台叫號看板。                                     | 開發中（[#71](https://github.com/YuanShuoHsu/biru-api/issues/71)） |
| 線上訂位       | 顧客自行線上訂位，系統自動安排桌位，並寄送確認與提醒信。                                  | 開發中（[#66](https://github.com/YuanShuoHsu/biru-api/issues/66)） |
| 出餐等候時間   | 依目前訂單量估算出餐時間，常態顯示給顧客。                                                | 開發中（[#68](https://github.com/YuanShuoHsu/biru-api/issues/68)） |

### （二）門市營運端

| 功能       | 說明                                                                       | 狀態                                                               |
| ---------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 菜單管理   | 管理菜單、品項、價格方案、加購與客製選項，支援多語系內容。                 | 已完成                                                             |
| 訂單管理   | 即時接收訂單、更新狀態，提供取餐看板。                                     | 已完成                                                             |
| 出單       | 訂單自動送往出單機列印。                                                   | 已完成                                                             |
| 候位管理   | 設定候位規則、叫號與管理號碼。                                             | 已完成                                                             |
| 庫存與叫貨 | 管理供應商、原料與配方，記錄庫存異動，低庫存自動通知。                     | 已完成                                                             |
| 出勤       | 員工資料、排班、打卡、請假與假別餘額。                                     | 已完成                                                             |
| 薪資       | 依當期勞健保級距與基本工資計算薪資，產生薪資單。                           | 已完成                                                             |
| 特殊營業日 | 設定臨時公休、颱風停業與節日營業時段，並一次處理受影響的訂單、候位與訂位。 | 開發中（[#62](https://github.com/YuanShuoHsu/biru-api/issues/62)） |

### （三）總部管理端

| 功能                   | 說明                                                           | 狀態                                                               |
| ---------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------ |
| 多門市與權限管理       | 各門市分開管理，成員分為擁有者、管理員、一般成員三種角色。     | 已完成                                                             |
| 營業報表               | 品項銷售報表，每日寄送營業摘要信。                             | 已完成                                                             |
| 行銷橫幅               | 管理前台首頁的宣傳橫幅。                                       | 已完成                                                             |
| 異動紀錄與資料復原     | 記錄後台的每一筆修改，誤刪的資料可在期限內復原。               | 已完成                                                             |
| 全品牌點數規則         | 點數的發放與有效期限改為全品牌統一設定。                       | 開發中（[#43](https://github.com/YuanShuoHsu/biru-api/issues/43)） |
| 點數對帳               | 統計各門市發出、兌換與到期的點數，計算跨店淨額。               | 開發中（[#44](https://github.com/YuanShuoHsu/biru-api/issues/44)） |
| 各門市金流與發票設定   | 每間門市使用各自的電子發票設定，金流可選擇品牌共用或門市自有。 | 開發中（[#45](https://github.com/YuanShuoHsu/biru-api/issues/45)） |
| 平台管理員與全平台總覽 | 平台管理員可管理所有門市，每日收到全平台營運總覽信。           | 開發中（[#56](https://github.com/YuanShuoHsu/biru-api/issues/56)） |

### 第一階段（MVP）

上表中「已完成」的功能：顧客點餐、付款、發票與會員，以及門市日常營運所需的菜單、訂單、庫存、出勤與薪資。

### 第二階段

上表中「開發中」的功能：多門市營運所需的點數、金流與發票設定，以及訂位、特殊營業日、現場候位與出餐等候時間等現場體驗改善。
