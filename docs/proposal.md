## 四、功能規劃

Biru 由三個部分組成：顧客使用的點餐網站、門市與總部使用的管理後台，以及兩者共用的後端服務。以下依使用對象分成三類，並標示目前進度：

- **已完成**：功能已開發完成。
- **開發中**：規格已確認，正在開發，附上對應的開發項目。

### （一）顧客端

| 功能           | 說明                                                                                      | 狀態                                                                 |
| -------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 線上點餐       | 提供內用、櫃檯、得來速與預約自取四種點餐方式；內用、櫃檯與得來速須掃描店內 QR code 點餐。 | 已完成                                                               |
| 線上付款       | 串接綠界科技金流，支援線上付款與退款。                                                    | 已完成                                                               |
| 電子發票       | 付款後自動開立電子發票，支援發票捐贈與統一編號查詢。                                      | 已完成                                                               |
| 優惠券         | 領取並於結帳時使用優惠券。                                                                | 已完成                                                               |
| 會員點數       | 消費累積點數，可兌換優惠券。                                                              | 已完成                                                               |
| 現場候位       | 取號並即時查看候位進度。                                                                  | 已完成                                                               |
| 多語系         | 介面支援繁體中文、簡體中文、英文、日文、韓文。                                            | 已完成                                                               |
| 候位限現場取號 | 須掃描門市入口 QR code 才能取號，並新增前台叫號看板。                                     | 已完成                                                               |
| 線上訂位       | 顧客自行線上訂位，系統自動安排桌位，並寄送確認與提醒信。                                  | 開發中（[#66](https://github.com/YuanShuoHsu/biru-api/issues/66)）   |
| 出餐等候時間   | 依目前訂單量估算出餐時間，常態顯示給顧客。                                                | 已完成                                                               |
| 共享點餐       | 多人以各自的手機加入同一張訂單一起點餐，由其中一人結帳付款。                              | 開發中（[#392](https://github.com/YuanShuoHsu/biru-api/issues/392)） |
| 站內付款       | 信用卡、Apple Pay 與 TWQR 直接在點餐頁面內完成付款，不必跳轉到金流頁面。                  | 開發中（[#480](https://github.com/YuanShuoHsu/biru-api/issues/480)） |
| 寄杯           | 會員一次購買多杯、分次領取，全品牌門市皆可領取。                                          | 開發中（[#459](https://github.com/YuanShuoHsu/biru-api/issues/459)） |
| 電子餐券       | 會員預先購買儲值金額、結帳時分次折抵，全品牌門市皆可使用。                                | 開發中（[#572](https://github.com/YuanShuoHsu/biru-api/issues/572)） |
| 推播通知       | 餐點完成與候位叫號時以瀏覽器推播通知顧客，門市人員也會收到營運通知。                      | 開發中（[#148](https://github.com/YuanShuoHsu/biru-api/issues/148)） |
| 餐點標示       | 菜單標示咖啡因、整杯糖量與熱量、茶與咖啡原料產地及過敏原。                                | 開發中（[#445](https://github.com/YuanShuoHsu/biru-api/issues/445)） |

### （二）門市營運端

| 功能           | 說明                                                                       | 狀態                                                                 |
| -------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 菜單管理       | 管理菜單、品項、價格方案、加購與客製選項，支援多語系內容。                 | 已完成                                                               |
| 訂單管理       | 即時接收訂單、更新狀態，提供取餐看板。                                     | 已完成                                                               |
| 出單           | 訂單自動送往出單機列印。                                                   | 已完成                                                               |
| 候位管理       | 設定候位規則、叫號與管理號碼。                                             | 已完成                                                               |
| 庫存與叫貨     | 管理供應商、原料與配方，記錄庫存異動，低庫存自動通知。                     | 已完成                                                               |
| 出勤           | 員工資料、排班、打卡、請假與假別餘額。                                     | 已完成                                                               |
| 薪資           | 依當期勞健保級距與基本工資計算薪資，產生薪資單。                           | 已完成                                                               |
| 特殊營業日     | 設定臨時公休、颱風停業與節日營業時段，並一次處理受影響的訂單、候位與訂位。 | 開發中（[#62](https://github.com/YuanShuoHsu/biru-api/issues/62)）   |
| 廚房出單畫面   | 吧台以平板查看製作中的訂單，逐項標記完成後出餐，不必依賴紙本工作單。       | 已完成                                                               |
| 現金機台帳     | 現金收付由現金機台自動記錄，人工只處理補鈔與收款，異常時自動通知。         | 開發中（[#121](https://github.com/YuanShuoHsu/biru-api/issues/121)） |
| 進貨驗收       | 依供應商一次點收多項食材，進貨與盤點分開記錄。                             | 開發中（[#443](https://github.com/YuanShuoHsu/biru-api/issues/443)） |
| 報廢紀錄       | 依原因記錄食材與成品的報廢，並在庫存報表中獨立列出。                       | 開發中（[#442](https://github.com/YuanShuoHsu/biru-api/issues/442)） |
| 門市例行檢查表 | 開店、打烊與冷藏冷凍溫度檢查由員工勾選並留存紀錄。                         | 開發中（[#444](https://github.com/YuanShuoHsu/biru-api/issues/444)） |
| 門市平面圖     | 每間門市各自設定樓層、桌位與座位的 3D 平面圖。                             | 開發中（[#118](https://github.com/YuanShuoHsu/biru-api/issues/118)） |

### （三）總部管理端

| 功能                   | 說明                                                                           | 狀態                                                                 |
| ---------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| 多門市與權限管理       | 各門市分開管理，成員分為擁有者、管理員、一般成員三種角色。                     | 已完成                                                               |
| 營業報表               | 品項銷售報表，每日寄送營業摘要信。                                             | 已完成                                                               |
| 行銷橫幅               | 管理前台首頁的宣傳橫幅。                                                       | 已完成                                                               |
| 異動紀錄與資料復原     | 記錄後台的每一筆修改，誤刪的資料可在期限內復原。                               | 已完成                                                               |
| 全品牌點數規則         | 點數的發放與有效期限改為全品牌統一設定。                                       | 已完成                                                               |
| 點數對帳               | 統計各門市發出、兌換與到期的點數，計算跨店淨額。                               | 開發中（[#44](https://github.com/YuanShuoHsu/biru-api/issues/44)）   |
| 各門市金流與發票設定   | 每間門市使用各自的電子發票設定，金流可選擇品牌共用或門市自有。                 | 開發中（[#45](https://github.com/YuanShuoHsu/biru-api/issues/45)）   |
| 平台管理員與全平台總覽 | 平台管理員可管理所有門市，每日收到全平台營運總覽信。                           | 已完成                                                               |
| 銷售與庫存報表         | 依日期、時段、付款方式與品項查看銷售，以及各原料的進出與耗用差異，可匯出 CSV。 | 開發中（[#119](https://github.com/YuanShuoHsu/biru-api/issues/119)） |
| 品牌商品目錄           | 菜單改為全品牌共用，各門市控制上架、價格與售完，並可有門市獨家品項。           | 開發中（[#461](https://github.com/YuanShuoHsu/biru-api/issues/461)） |

### 第一階段（MVP）

開幕前必須具備的功能，即上表中「已完成」與「開發中」的項目：顧客點餐、付款、發票與會員，門市日常營運所需的菜單、訂單、庫存、出勤與薪資，以及多門市營運所需的點數、金流與發票設定。

### 第二階段

開幕後再評估、尚未排入開發的功能：餐後評價、外送平台串接與離線點餐。
