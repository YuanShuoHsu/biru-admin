# 店內空間風格

牆面、地板、燈光與家具的方向，給裝潢設計與估價參考。設備擺放與動線見[店內設備擺放規劃](layout.md)，這裡只談看起來的樣子。以下是依品牌整理的方向草案，「狀態」欄的**待定**要等店家看過參考店家與裝潢提案後拍板。

## 方向

延續[品牌](brand/README.md)的調性：簡約、溫潤、日系咖啡店氛圍，和[品牌餐具](tableware.md#設計方向)用同一套元素。空間是背景，讓餐點、飲品和人成為主角；Logo 與品牌色只出現在少數重點位置，不整面鋪滿。

## 色彩

照[品牌配色](brand/README.md#配色)分配面積：

| 顏色     | 用在哪裡                                           | 面積   | 狀態 |
| -------- | -------------------------------------------------- | ------ | ---- |
| 奶泡白   | 牆面、天花板主色                                   | 大面積 | 待定 |
| 木色     | 桌面、層架、吧台前緣（不是品牌色，用來帶出溫潤感） | 中面積 | 待定 |
| 藍灰     | 吧台立面或一面主牆、椅子或窗框等點綴               | 小面積 | 待定 |
| 拿鐵琥珀 | 燈光的色調、少量布料或陶器                         | 點綴   | 待定 |

藍灰牆面上不要直接放彩色 Logo（輪廓會消失，見[底色](brand/README.md#底色)）；要放 Logo 的牆用奶泡白或木色。

## 材質

| 位置       | 方向                                                           | 狀態 |
| ---------- | -------------------------------------------------------------- | ---- |
| 桌面、層架 | 淺色木紋，和內用的木質托盤一致                                 | 待定 |
| 吧台前緣   | 木作或藍灰色系面材，配合[吧台立面](layout.md#吧台立面)的高低段 | 待定 |
| 地板       | 耐刮、好清潔的淺灰或淺木紋；寵物友善，避免容易打滑的亮面       | 待定 |
| 椅子       | 木頭或布面，布面選可拆洗的                                     | 待定 |
| 餐具       | 照[內用餐具](tableware.md#內用餐具)：陶瓷、玻璃、木質          | 已定 |

寵物可以落地（見[用餐規定](dining-rules.md)），地板與椅腳要耐抓、好擦。

## 燈光

| 區域         | 方向                                                     | 狀態 |
| ------------ | -------------------------------------------------------- | ---- |
| 座位區       | 暖色溫的間接照明為主，桌面另有重點照明讓餐點好看、好拍   | 待定 |
| 吧台         | 工作面要亮且均勻，顧客視線看不到燈具本體                 | 待定 |
| 點餐與取餐處 | 比座位區亮，讓顧客一眼找到                               | 待定 |
| 二樓         | 和一樓同一套色溫；遠距辦公的座位要有足夠的桌面亮度與插座 | 待定 |

## 品牌元素

- Logo 只放在入口、吧台立面或點餐處其中一兩個位置；招牌與標示見[招牌與店內標示](signage.md)。
- 碧露的故事（見[品牌](brand/README.md#碧露的故事)）可以做成一面小牆或菜單背面的短文。
- 店內兩隻家貓是店家的寵物，不當招牌宣傳（見[用餐規定](dining-rules.md)）：空間裡的貓元素來自 Logo 與碧露的故事，不做「店貓」看板或照片牆。
