# 食譜

建進後台後一律以資料庫為準；本文件的欄位逐步對齊資料庫，資料不一致時改本文件。

## 格式說明

| 欄位     | 資料庫欄位                                    | 說明                                                                     |
| -------- | --------------------------------------------- | ------------------------------------------------------------------------ |
| 標題     | `recipe.name`                                 | 餐點名稱，與菜單品項同名時可自動綁定                                     |
| 品名     | 菜單品項 `menuItem.name`                      | 五種語言（`zh-TW`、`zh-CN`、`en`、`ja`、`ko`），菜單上顯示的名稱         |
| 說明     | 菜單品項 `menuItem.description`               | 五種語言；寫清楚主要風味，並列出過敏原                                   |
| 類別     | 菜單分類                                      | 不屬於食譜                                                               |
| 份量     | `recipe.recipeYield`                          | 一次做出幾份，只能是正整數                                               |
| 材料     | `recipeIngredient.ingredientId`               | 名稱與 `ingredients.md` 一字不差                                         |
| 用量     | `recipeIngredient.requiredQuantity`           | 整鍋的量，單位是該食材的基準單位；一律是下鍋前的生重，半成品以成品重量計 |
| 步驟     | `recipe.recipeInstructions`                   | 每步一筆                                                                 |
| 售價     | 菜單品項 `offer.price`                        | 建議零售價，單份                                                         |
| 推薦甜度 | 菜單品項 `recommendedSweetnessLevel`          | 甜度可調的飲品才寫，點餐時在該甜度旁標示「推薦」                         |
| 推薦冰量 | 菜單品項 `recommendedServingTemperatureLevel` | 有冷熱供應的飲品才寫，點餐時在該冰量或溫度旁標示「推薦」                 |
| 小計     | 後端計算                                      | 用量 × 單位成本，不入庫                                                  |
| 總成本   | 後端計算                                      | 各材料小計合計，不含耗材，不入庫                                         |
| 每份成本 | 不入庫                                        | 總成本 ÷ 份量                                                            |
| 毛利     | 不入庫                                        | 售價 − 每份成本                                                          |
| 毛利率   | 不入庫                                        | （售價 − 每份成本）÷ 售價 × 100%                                         |

定價一律以每份為基準；總成本是整鍋的量，不可直接與售價相減。

售價以桃園市大園區（大園店）的消費水準為基準，與桃園地區同類店家比較，參考店家見[參考店家](references.md)。

### 半成品與加量

- 半成品（如紅醬、白醬、優格）統一放在「半成品」，份量寫 1 鍋，不寫類別、不綁菜單品項，另外列一項食材；用到它的餐點把它當材料。
- 品項不分大小份，一個品項只能有一份食譜，扣庫存也是依品項計算；要加量就用[加點](#加點)選項。

### 杯型

熱飲只有 12oz 一種；冷飲分小杯 12oz、大杯 16oz（見[餐具清單](tableware.md)）。飲品食譜一律以 12oz、全糖、正常冰為準，大杯照下表的糖量與冰量調整，其餘材料照容量比例放大。

### 甜度

甜度是品項屬性（不適用／固定／可調），不是客製選項，系統不會依甜度扣庫存。吧檯用果糖定量機出甘蔗液糖，甜度名稱就是「幾分糖」，店員按甜度鍵即可；每分的糖重依杯型固定，所有飲品共用，是機器的設定值。各飲品的建議甜度以「推薦甜度」標示，不另改糖量。全糖約為業界大杯（700ml）50g 糖依容量換算；糖量指額外加入的糖重。

甘蔗液糖用[台糖甘蔗液糖](ingredients.md)，成分只有砂糖與水，錘度 ≥74°Bx，每 100g 含糖約 71.8g、每 ml 約含 0.98g 糖（密度約 1.37g/ml）。每分的液糖：12oz 2.5ml、16oz 3.5ml，即果糖定量機各鍵的設定值；糖重為換算值，[果糖定量機](equipment.md#果糖定量機選型)到機後以秤校正定案，並向晉源確認可否設定到 0.5ml。液糖含轉化糖（果糖、葡萄糖），同樣糖重喝起來比蔗糖略甜，試飲後再微調；天冷變稠時開啟果糖定量機的加熱保溫。

| 甜度   | 分  | 12oz 液糖 | 12oz 糖重 | 16oz 液糖 | 16oz 糖重 |
| ------ | --- | --------- | --------- | --------- | --------- |
| 全糖   | 10  | 25ml      | 約 24.6g  | 35ml      | 約 34.4g  |
| 少糖   | 7   | 17.5ml    | 約 17.2g  | 24.5ml    | 約 24.1g  |
| 半糖   | 5   | 12.5ml    | 約 12.3g  | 17.5ml    | 約 17.2g  |
| 微糖   | 3   | 7.5ml     | 約 7.4g   | 10.5ml    | 約 10.3g  |
| 一分糖 | 1   | 2.5ml     | 約 2.5g   | 3.5ml     | 約 3.4g   |
| 無糖   | 0   | 0ml       | 0g        | 0ml       | 0g        |

### 冰量與溫度

冰量與溫度是品項屬性（有冷熱供應時客人必選），不是客製選項。冰量以實際重量計，依杯型固定、所有飲品共用，各飲品的建議冰量以「推薦冰量」標示；每降一級減同樣的重量：12oz 每級 40g、16oz 每級 50g，正常冰以業界 500ml 杯約 150g 為基準。依業界做法杯量固定，少放的冰以飲料補到同一刻度；去冰是飲料先加冰降溫再濾掉冰塊，杯中不留冰。冰塊由製冰機供應，不列進食譜材料。

| 冰量   | 12oz | 16oz |
| ------ | ---- | ---- |
| 正常冰 | 120g | 150g |
| 少冰   | 80g  | 100g |
| 微冰   | 40g  | 50g  |
| 去冰   | 0g   | 0g   |

熱飲依業界常見出杯溫度：

| 溫度 | 出杯溫度   |
| ---- | ---------- |
| 溫   | 約 55°C    |
| 熱   | 約 65–70°C |

### 辣度

辣度是客製選項，不是品項屬性：建一個選項群組「辣度」，單選必選（最少、最多都選 1），五個選項都不加價，掛在每個義大利麵品項上。各選項綁一份食譜，客人選了就依該食譜扣乾辣椒片；「不辣」不綁食譜。品項食譜因此不含乾辣椒片，成本與售價也不含。出餐時用 0.25g 的量匙，在爆香蒜時依辣度加入。

| 選項 | 量匙 | 選項食譜       |
| ---- | ---- | -------------- |
| 不辣 | 0 匙 | 不綁食譜       |
| 微辣 | 1 匙 | 乾辣椒片 0.25g |
| 小辣 | 2 匙 | 乾辣椒片 0.5g  |
| 中辣 | 3 匙 | 乾辣椒片 0.75g |
| 大辣 | 4 匙 | 乾辣椒片 1g    |

### 加點

加麵與加主料也是客製選項：建一個選項群組「加點」，多選、非必選，掛在每個義大利麵品項上。各選項綁一份食譜，客人選了就依該食譜扣庫存；品項食譜、成本與售價都不含加點。加麵是讓熟麵從約 160g 加到約 200g（乾麵 65g 煮熟約 160g）。加主料一律是一份的半份：有主餐的以主餐份量為一份，沒有的以下表的標準量為一份。主餐的 CP 值要比加點高，所以加主料的加價不能低於主餐差價的一半，例如白酒蛤蠣比蒜炒貴 140 元、多 200g 蛤蠣，加蛤蠣 100g 至少 70 元；之後推出這些主料的主餐，主料給一整份並照這條定價。

| 選項   | 加價 | 選項食譜                           | 成本 | 毛利率 | 出餐                                         |
| ------ | ---- | ---------------------------------- | ---- | ------ | -------------------------------------------- |
| 加麵   | 20元 | 義大利麵 15g                       | 2元  | 92.0%  | 與麵一起下鍋                                 |
| 加野菇 | 20元 | 鴻喜菇 30g（一份 60g，同松露野菇） | 7元  | 65.8%  | 切除根部撥散，爆香蒜後下鍋炒到出水上色       |
| 加培根 | 40元 | 培根 45g（一份 90g，約 6 片）      | 11元 | 73.2%  | 切小段，與蒜一起小火煸出油                   |
| 加雞肉 | 50元 | 雞腿肉 90g（一份 180g，約 1 片）   | 21元 | 58.8%  | 前一天移到冷藏解凍；切塊，爆香蒜前先煎到全熟 |
| 加鮮蝦 | 60元 | 蝦仁 45g（一份 90g，約 12 隻）     | 26元 | 57.4%  | 冷藏或冷水解凍；爆香蒜後下鍋炒到變色         |
| 加蛤蠣 | 70元 | 蛤蠣 100g（一份 200g，同白酒蛤蠣） | 33元 | 52.6%  | 同白酒蛤蠣先吐沙；倒醬前下鍋，蓋鍋燜到全開   |

### 奶蓋

加奶蓋也是客製選項：建一個選項群組「奶蓋」，單選、非必選，掛在美式咖啡、拿鐵、碧露咖啡上。各選項綁一份食譜，客人選了就依該食譜扣庫存；品項食譜、成本與售價都不含奶蓋。一鍋奶蓋做 4 杯，每杯用一鍋的 1/4，出餐時用湯匙背面輕輕鋪在飲料最上層。

| 選項     | 加價 | 選項食譜                  | 成本               |

| 奶蓋     | 待定 | [奶蓋](#奶蓋-1) 62g       | 17元               |
| 抹茶奶蓋 | 待定 | [抹茶奶蓋](#抹茶奶蓋) 64g | 33元               |
| 焙茶奶蓋 | 待定 | [焙茶奶蓋](#焙茶奶蓋) 64g | 29元               |
| 咖啡奶蓋 | 待定 | [咖啡奶蓋](#咖啡奶蓋) 71g | 17元（未含咖啡豆） |

### 封口方式

外帶飲料的封口也是客製選項：建一個選項群組「封口方式」，單選必選，兩個選項都不加價，掛在每個飲品品項上（冷熱飲都掛）。內用用玻璃杯，所以兩個選項的可販售點餐模式都只勾櫃檯、自取、得來速，不勾內用。外送平台的訂單一律封膜。

| 選項 | 說明                  |
| ---- | --------------------- |
| 杯蓋 | 90mm 杯蓋，可直接就口 |
| 封膜 | 90mm 封口膜，搭配吸管 |

內用點餐不顯示這個群組也不要求選擇，需 [biru-api#367](https://github.com/YuanShuoHsu/biru-api/pull/367) 與 [biru#123](https://github.com/YuanShuoHsu/biru/pull/123) 上線後才生效；上線前內用會被要求必選而無法下單。

## 烘焙甜點

### 奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 用量  | 小計 |
| ------ | ----- | ---- |
| 吉利丁 | 8g    | 9元  |
| 牛奶   | 300ml | 22元 |
| 鮮奶油 | 100ml | 39元 |
| 糖     | 8g    | <1元 |
| 鹽     | 0.4g  | <1元 |
| 香草精 | 0.8ml | <1元 |

**總成本：** 72 元（每份 17.89 元）

#### 步驟

1. 吉利丁 8g（約 4 片）泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 離火後加入香草精攪拌均勻。
4. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
5. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

**售價：** 60 元（毛利 42.11 元，毛利率 70.2%）

**總成本：** 70 元（每 100g 約 24.5 元，未含咖啡豆）

#### 步驟

1. 咖啡豆 18g 萃取雙份濃縮咖啡（約 36g），趁熱拌入糖 8g、鹽 0.4g 至溶解，放涼後加入冰牛奶 80ml。
2. 冰的鮮奶油 160ml、香草精 0.8ml 與步驟 1 的液體倒入 [Vitamix 打發杯](equipment.md#吧台區)。
3. 從最低速開始，慢慢加速打到七分發（可流動、會慢慢攤平）。
4. 冷藏保存。

#### 備註

- 用於[奶蓋](#奶蓋)選項群組的「咖啡奶蓋」選項，每杯 71g（一鍋的 1/4）。
- 原配方以重量計：牛奶 80g、鮮奶油 160g、香草精 0.8g，基準單位是 ml，密度以約 1 換算。
- 濃縮用量沿用原本的雙份（約 36g），待試做後定案。
- 成品重量以食材合計估算，首次製作請秤重校正。
- 冷藏當日用完。
