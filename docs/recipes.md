# 食譜

## 格式說明

| 欄位     | 說明                             |
| -------- | -------------------------------- |
| 份量     | 一次做出幾杯                     |
| 用量     | 材料表的量，是整鍋的量           |
| 總成本   | 各材料用量的成本合計，不含耗材   |
| 每份成本 | 總成本 ÷ 份量                    |
| 售價     | 建議零售價，單杯                 |
| 毛利     | 售價 − 每份成本                  |
| 毛利率   | （售價 − 每份成本）÷ 售價 × 100% |

定價一律以每份為基準；總成本是整鍋的量，不可直接與售價相減。

## 烘焙甜點

### 奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 用量  | 小計 |
| ------ | ----- | ---- |
| 吉利丁 | 6g    | 7元  |
| 牛奶   | 300ml | 27元 |
| 鮮奶油 | 100ml | 39元 |
| 糖     | 8g    | <1元 |
| 鹽     | 0.8g  | <1元 |
| 香草精 | 2ml   | 2元  |

**總成本：** 75 元（每份 18.80 元）

#### 步驟

1. 吉利丁約 3 片泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 離火後加入香草精攪拌均勻。
4. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
5. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

**售價：** 60 元（毛利 41.20 元，毛利率 68.7%）

### 抹茶奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 用量  | 小計 |
| ------ | ----- | ---- |
| 吉利丁 | 6g    | 7元  |
| 牛奶   | 300ml | 27元 |
| 鮮奶油 | 100ml | 39元 |
| 抹茶粉 | 4g    | 38元 |
| 糖     | 8g    | <1元 |
| 鹽     | 0.8g  | <1元 |
| 香草精 | 2ml   | 2元  |

**總成本：** 113 元（每份 28.30 元）

#### 步驟

1. 吉利丁約 3 片泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 抹茶粉不另外加水調開，直接取少量熱牛奶液沖開拌勻，再倒回鍋中。
4. 離火後加入香草精攪拌均勻。
5. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
6. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

**售價：** 90 元（毛利 61.70 元，毛利率 68.6%）

#### 備註

- 抹茶粉小計依 100g 包裝（950元）計；改用 500g 包裝為 30元，總成本 106 元（每份 26.40 元）。

## 醬料

### 紅醬

**類別：** 醬料  
**份量：** 約 2300g（小份 19 份、大份 15 份）

#### 材料

| 材料   | 用量  | 小計  |
| ------ | ----- | ----- |
| 牛番茄 | 1500g | 207元 |
| 洋蔥   | 200g  | 11元  |
| 番茄糊 | 100g  | 39元  |
| 西芹   | 100g  | 13元  |
| 紅蘿蔔 | 100g  | 8元   |
| 蒜頭   | 20g   | 6元   |

**總成本：** 284 元（每 100g 約 12.3 元）

#### 步驟

1. 約牛番茄 16 顆、洋蔥 1 顆、西芹 2 根、紅蘿蔔 1/2 根切塊，蒜頭約 4 顆切末。
2. 全部食材與番茄糊 4 大匙入鍋，加水 1000ml。
3. 不加蓋煮 30 分鐘。

#### 用量

| 份別 | 麵體（乾） | 麵體（熟） | 紅醬 | 紅醬成本 |
| ---- | ---------- | ---------- | ---- | -------- |
| 小份 | 65g        | 160g       | 120g | 15元     |
| 大份 | 80g        | 200g       | 150g | 18元     |

#### 備註

- 成品重量為估算：食材 2020g 加水 1000ml，不加蓋煮 30 分鐘蒸發約四分之一。首次製作請秤重校正。
