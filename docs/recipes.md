# 食譜

建進後台後一律以資料庫為準；本文件的欄位逐步對齊資料庫，資料不一致時改本文件。

## 格式說明

| 欄位     | 資料庫欄位                          | 說明                                 |
| -------- | ----------------------------------- | ------------------------------------ |
| 標題     | `recipe.name`                       | 餐點名稱，與菜單品項同名時可自動綁定 |
| 類別     | 菜單分類                            | 不屬於食譜                           |
| 份量     | `recipe.recipeYield`                | 一次做出幾份，只能是正整數           |
| 材料     | `recipeIngredient.ingredientId`     | 名稱與 `ingredients.md` 一字不差     |
| 用量     | `recipeIngredient.requiredQuantity` | 整鍋的量，單位是該食材的基準單位     |
| 步驟     | `recipe.recipeInstructions`         | 每步一筆                             |
| 售價     | 菜單品項 `offer.price`              | 建議零售價，單份                     |
| 小計     | 後端計算                            | 用量 × 單位成本，不入庫              |
| 總成本   | 後端計算                            | 各材料小計合計，不含耗材，不入庫     |
| 每份成本 | 不入庫                              | 總成本 ÷ 份量                        |
| 毛利     | 不入庫                              | 售價 − 每份成本                      |
| 毛利率   | 不入庫                              | （售價 − 每份成本）÷ 售價 × 100%     |

定價一律以每份為基準；總成本是整鍋的量，不可直接與售價相減。

### 半成品與大小份

- 半成品（如紅醬）的份量寫 1 鍋，不綁菜單品項，另外列一項食材；用到它的餐點把它當材料。
- 大小份拆成兩個菜單品項，各寫一份食譜。一個品項只能有一份食譜，扣庫存也是依品項計算。

## 烘焙甜點

### 奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 用量  | 小計 |
| ------ | ----- | ---- |
| 吉利丁 | 8g    | 9元  |
| 牛奶   | 300ml | 22元 |
| 鮮奶油 | 100ml | 39元 |
| 糖     | 8g    | <1元 |
| 鹽     | 0.4g  | <1元 |
| 香草精 | 0.8ml | <1元 |

**總成本：** 72 元（每份 17.89 元）

#### 步驟

1. 吉利丁 8g（約 4 片）泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 離火後加入香草精攪拌均勻。
4. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
5. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

**售價：** 60 元（毛利 42.11 元，毛利率 70.2%）

### 抹茶奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 用量  | 小計 |
| ------ | ----- | ---- |
| 吉利丁 | 8g    | 9元  |
| 牛奶   | 300ml | 22元 |
| 鮮奶油 | 100ml | 39元 |
| 抹茶粉 | 4g    | 30元 |
| 糖     | 8g    | <1元 |
| 鹽     | 0.4g  | <1元 |
| 香草精 | 0.8ml | <1元 |

**總成本：** 102 元（每份 25.49 元）

#### 步驟

1. 吉利丁 8g（約 4 片）泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 抹茶粉不另外加水調開，直接取少量熱牛奶液沖開拌勻，再倒回鍋中。
4. 離火後加入香草精攪拌均勻。
5. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
6. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

**售價：** 90 元（毛利 64.51 元，毛利率 71.7%）

## 醬料

### 紅醬

**類別：** 醬料  
**份量：** 1 鍋（成品約 2300g，可出小份 19 份或大份 15 份）

#### 材料

| 材料   | 用量   | 小計  |
| ------ | ------ | ----- |
| 牛番茄 | 1500g  | 207元 |
| 洋蔥   | 200g   | 11元  |
| 番茄糊 | 100g   | 39元  |
| 西芹   | 100g   | 13元  |
| 紅蘿蔔 | 100g   | 8元   |
| 蒜頭   | 20g    | 6元   |
| 水     | 1000ml | <1元  |

**總成本：** 284 元（每 100g 約 12.3 元）

#### 步驟

用量一律以克數為準，括號內的顆數、根數與大匙只是估計，實際要秤重。

1. 牛番茄 1500g（約 8 顆）、洋蔥 200g（約 1 顆）、西芹 100g（約 2 根）、紅蘿蔔 100g（約 1/2 根）切塊，蒜頭 20g（約 4 顆）切末。
2. 全部食材與番茄糊 100g（約 6 大匙）入鍋，加水 1000ml。
3. 不加蓋煮 30 分鐘。

#### 用量

| 份別 | 麵體（乾） | 麵體（熟） | 紅醬 | 紅醬成本 |
| ---- | ---------- | ---------- | ---- | -------- |
| 小份 | 65g        | 160g       | 120g | 15元     |
| 大份 | 80g        | 200g       | 150g | 18元     |

#### 備註

- 成品重量為估算：食材 2020g 加水 1000ml，不加蓋煮 30 分鐘蒸發約四分之一。首次製作請秤重校正。
- 用量表先留著，建立義大利麵的大小份品項時改寫成各自的食譜材料。
- 番茄糊 1 大匙約 16g，100g 約 6 大匙。
