# 食譜

建進後台後一律以資料庫為準；本文件的欄位逐步對齊資料庫，資料不一致時改本文件。

## 格式說明

| 欄位     | 資料庫欄位                          | 說明                                 |
| -------- | ----------------------------------- | ------------------------------------ |
| 標題     | `recipe.name`                       | 餐點名稱，與菜單品項同名時可自動綁定 |
| 類別     | 菜單分類                            | 不屬於食譜                           |
| 份量     | `recipe.recipeYield`                | 一次做出幾份，只能是正整數           |
| 材料     | `recipeIngredient.ingredientId`     | 名稱與 `ingredients.md` 一字不差     |
| 用量     | `recipeIngredient.requiredQuantity` | 整鍋的量，單位是該食材的基準單位     |
| 步驟     | `recipe.recipeInstructions`         | 每步一筆                             |
| 售價     | 菜單品項 `offer.price`              | 建議零售價，單份                     |
| 小計     | 後端計算                            | 用量 × 單位成本，不入庫              |
| 總成本   | 後端計算                            | 各材料小計合計，不含耗材，不入庫     |
| 每份成本 | 不入庫                              | 總成本 ÷ 份量                        |
| 毛利     | 不入庫                              | 售價 − 每份成本                      |
| 毛利率   | 不入庫                              | （售價 − 每份成本）÷ 售價 × 100%     |

定價一律以每份為基準；總成本是整鍋的量，不可直接與售價相減。

### 半成品與大小份

- 半成品（如紅醬、白醬、優格）統一放在「半成品」，份量寫 1 鍋，不寫類別、不綁菜單品項，另外列一項食材；用到它的餐點把它當材料。
- 大小份拆成兩個菜單品項，各寫一份食譜。一個品項只能有一份食譜，扣庫存也是依品項計算。

### 甜度

甜度是品項屬性（不適用／固定／可調），不是客製選項，系統不會依甜度扣庫存。飲品食譜一律以全糖寫糖或糖漿用量，各甜度按下表比例調整。

| 甜度   | 糖量比例 |
| ------ | -------- |
| 全糖   | 100%     |
| 少糖   | 70%      |
| 半糖   | 50%      |
| 微糖   | 30%      |
| 一分糖 | 10%      |
| 無糖   | 0%       |

### 冰量與溫度

冰量與溫度是品項屬性（有冷熱供應時客人必選），不是客製選項。飲品食譜一律以正常冰寫冰塊用量，各冰量按下表比例調整；杯量固定，少放的冰以飲料補到同一刻度。冰塊由製冰機供應，不列進食譜材料。

| 冰量／溫度 | 冰塊比例 | 飲品溫度   |
| ---------- | -------- | ---------- |
| 正常冰     | 100%     |            |
| 少冰       | 70%      |            |
| 微冰       | 30%      |            |
| 去冰       | 0%       | 冷藏溫度   |
| 溫         | 0%       | 約 55–60°C |
| 熱         | 0%       | 約 70–75°C |

### 辣度

辣度是客製選項，不是品項屬性：建一個選項群組「辣度」，單選必選（最少、最多都選 1），五個選項都不加價，掛在每個義大利麵品項上。各選項綁一份食譜，客人選了就依該食譜扣乾辣椒片；「不辣」不綁食譜。品項食譜因此不含乾辣椒片，成本與售價也不含。出餐時在爆香蒜時依客人選的辣度加入。

| 選項 | 選項食譜       |
| ---- | -------------- |
| 不辣 | 不綁食譜       |
| 微辣 | 乾辣椒片 0.25g |
| 小辣 | 乾辣椒片 0.5g  |
| 中辣 | 乾辣椒片 0.75g |
| 大辣 | 乾辣椒片 1g    |

## 烘焙甜點

### 奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 用量  | 小計 |
| ------ | ----- | ---- |
| 吉利丁 | 8g    | 9元  |
| 牛奶   | 300ml | 22元 |
| 鮮奶油 | 100ml | 39元 |
| 糖     | 8g    | <1元 |
| 鹽     | 0.4g  | <1元 |
| 香草精 | 0.8ml | <1元 |

**總成本：** 72 元（每份 17.89 元）

#### 步驟

1. 吉利丁 8g（約 4 片）泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 離火後加入香草精攪拌均勻。
4. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
5. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

**售價：** 60 元（毛利 42.11 元，毛利率 70.2%）

## 義大利麵

麵體一律用直麵。煮麵用的水與鹽是共用的，不列進各品項的材料。

### 紅醬義大利麵（小份）

**類別：** 義大利麵  
**份量：** 1 份

#### 材料

| 材料         | 用量 | 小計 |
| ------------ | ---- | ---- |
| 義大利麵     | 65g  | 7元  |
| 紅醬         | 120g | 15元 |
| 橄欖油       | 10ml | 5元  |
| 蒜頭         | 5g   | 1元  |
| 帕瑪森起司粉 | 5g   | 4元  |
| 義大利香料   | 0.3g | <1元 |
| 雞高湯       | 50g  | <1元 |

**總成本：** 33 元（每份 33.16 元）

#### 步驟

1. 煮一鍋滾水，義大利麵 65g 下鍋，煮約 11 分鐘到彈牙，撈起前留 50ml 煮麵水。
2. 鍋中倒入橄欖油 10ml，小火爆香蒜末 5g（依辣度加入乾辣椒片）。
3. 加入紅醬 120g、雞高湯 50g（一瓢）與 50ml 煮麵水，煮到冒泡。
4. 放入煮好的麵拌炒到醬汁收稠。
5. 盛盤，撒上帕瑪森起司粉 5g、義大利香料 0.3g。

#### 定價

**售價：** 160 元（毛利 126.84 元，毛利率 79.3%）
