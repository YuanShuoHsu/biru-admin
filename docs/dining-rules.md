# 用餐規定

前台點餐頁上方的告示卡與後台菜單頁的菜單卡是同一筆菜單資料：每間門市一份菜單，卡片顯示菜單名稱、說明文字與圖片。這塊用來放用餐規定告示。

建進後台後一律以資料庫為準；本文件的欄位逐步對齊資料庫，資料不一致時改本文件。

## 格式說明

| 欄位     | 資料庫欄位            | 說明                                                         |
| -------- | --------------------- | ------------------------------------------------------------ |
| 標題     | `menu.name`           | 告示卡標題，五種語言都要填                                   |
| 告示文字 | `menu.description`    | 五種語言（`zh-TW`、`zh-CN`、`en`、`ja`、`ko`）；一條規定一行 |
| 圖片     | `menu.image`          | 告示卡圖片，在後台菜單頁上傳                                 |
| 門市     | `menu.organizationId` | 一間門市一份菜單；各門市規定不同時，分門市寫在「門市差異」   |

## 規定

依顧客到店的順序分成四類，告示也照這個順序寫。「狀態」欄：**已定**是已決定的做法或法規要求，**待定**是還沒決定、需要店家拍板的項目，不要當成已決定寫進告示。目前全部已定。

| 分類     | 項目     | 規定                                                                  | 適用點餐方式       | 狀態 | 依據                                                                                        |
| -------- | -------- | --------------------------------------------------------------------- | ------------------ | ---- | ------------------------------------------------------------------------------------------- |
| 點餐取餐 | 點餐     | 內用、櫃檯、得來速須掃描店內 QR code 點餐；預約自取可遠端點餐         | 全部               | 已定 | [企劃書](proposal.md)                                                                       |
| 點餐取餐 | 點餐裝置 | 沒有手機的顧客可使用店內平板點餐與取號                                | 內用、櫃檯、得來速 | 已定 |                                                                                             |
| 點餐取餐 | 取餐     | 依取餐看板顯示的號碼取餐                                              | 全部               | 已定 |                                                                                             |
| 內用規定 | 候位     | 客滿時於門市入口掃描 QR code 取號，依叫號看板入座                     | 內用               | 已定 | [biru-api#71](https://github.com/YuanShuoHsu/biru-api/issues/71)（開發中）                  |
| 內用規定 | 最低消費 | 內用每人低消任一餐點                                                  | 內用               | 已定 |                                                                                             |
| 內用規定 | 外食     | 禁帶外食                                                              | 內用               | 已定 |                                                                                             |
| 內用規定 | 用餐時間 | 個人用餐不限時；2 人以上為團體，客滿時團體用餐限 2 小時，未客滿不限時 | 內用               | 已定 |                                                                                             |
| 內用規定 | 餐具回收 | 用餐後將餐具放到自助回收區                                            | 內用               | 已定 | [工作動線](layout.md#工作動線)                                                              |
| 友善空間 | 遠端工作 | 遠端工作友善，可作為共享辦公空間使用                                  | 內用               | 已定 |                                                                                             |
| 友善空間 | 插座     | 每個座位都有插座                                                      | 內用               | 已定 |                                                                                             |
| 友善空間 | 兒童     | 提供兒童座椅                                                          | 內用               | 已定 |                                                                                             |
| 友善空間 | 寵物     | 寵物友善                                                              | 內用               | 已定 |                                                                                             |
| 友善空間 | 店貓     | 店內有兩隻貓咪偶爾出沒，不一定在店內                                  | 內用               | 已定 |                                                                                             |
| 店內規範 | 禁菸     | 室內全面禁菸，入口須設明顯禁菸標示，不得供應與吸菸有關之器物          | 全部               | 已定 | [菸害防制法第 15 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=L0040001&flno=15) |

## 標籤

告示第一行放 hashtag，讓顧客一眼看到店的特色；每個標籤都要對得上上表的一條規定，規定改了標籤跟著改。

| 標籤          | 對應規定 |
| ------------- | -------- |
| #遠端工作友善 | 遠端工作 |
| #共享辦公     | 遠端工作 |
| #全座位插座   | 插座     |
| #一人不限時   | 用餐時間 |
| #寵物友善     | 寵物     |
| #店貓出沒     | 店貓     |
| #親子友善     | 兒童     |

## 門市差異

目前只有大園店，沒有門市差異。之後有門市規定不同時，在這裡逐條列出門市、項目與規定。

## 告示文字

依上表「已定」的項目寫成；規定變動時，先改上表，再改這裡，最後貼到後台菜單。格式：第一行是標籤，接著依分類各一段，分類標題用【】，每條規定一行、前面加「・」，段與段之間空一行。後台菜單的說明欄位直接換行即可，前台與後台菜單卡都會照行顯示。

| 語言    | 標題              |
| ------- | ----------------- |
| `zh-TW` | 用餐須知          |
| `zh-CN` | 用餐须知          |
| `en`    | Dining Guidelines |
| `ja`    | ご利用案内        |
| `ko`    | 이용 안내         |

### `zh-TW`

```text
#遠端工作友善 #共享辦公 #全座位插座 #一人不限時 #寵物友善 #店貓出沒 #親子友善

【點餐取餐】
・內用、櫃檯與得來速請掃描店內 QR code 點餐，沒有手機可使用店內平板
・預約自取可線上點餐
・請依取餐看板號碼取餐

【內用規定】
・客滿時請於門市入口掃描 QR code 取號候位
・每人低消任一餐點，禁帶外食
・個人用餐不限時；2 人以上為團體，客滿時限用餐 2 小時
・用餐後請將餐具放到自助回收區

【友善空間】
・歡迎遠端工作，可作為共享辦公空間
・每個座位都有插座
・提供兒童座椅
・歡迎攜帶寵物；店內有兩隻貓咪偶爾出沒，不一定在店內

【店內規範】
・室內全面禁菸
```
