# 用餐規定

前台點餐頁上方的告示卡與後台菜單頁的菜單卡是同一筆菜單資料：每間門市一份菜單，卡片顯示菜單名稱、說明文字與圖片。這塊用來放用餐規定告示。

建進後台後一律以資料庫為準；本文件的欄位逐步對齊資料庫，資料不一致時改本文件。

## 格式說明

| 欄位     | 資料庫欄位            | 說明                                                                     |
| -------- | --------------------- | ------------------------------------------------------------------------ |
| 標題     | `menu.name`           | 告示卡標題，五種語言都要填                                               |
| 告示文字 | `menu.description`    | 五種語言（`zh-TW`、`zh-CN`、`en`、`ja`、`ko`）；前台不保留換行，寫成一段 |
| 圖片     | `menu.image`          | 告示卡圖片，在後台菜單頁上傳                                             |
| 門市     | `menu.organizationId` | 一間門市一份菜單；各門市規定不同時，分門市寫在「門市差異」               |

## 規定

「狀態」欄：**已定**是已決定的做法或法規要求，**待定**是還沒決定、需要店家拍板的項目，不要當成已決定寫進告示。

| 項目     | 規定                                                          | 適用點餐方式       | 狀態 | 依據                                                                                        |
| -------- | ------------------------------------------------------------- | ------------------ | ---- | ------------------------------------------------------------------------------------------- |
| 點餐     | 內用、櫃檯、得來速須掃描店內 QR code 點餐；預約自取可遠端點餐 | 全部               | 已定 | [企劃書](proposal.md)                                                                       |
| 點餐裝置 | 沒有手機的顧客可使用店內平板點餐與取號                        | 內用、櫃檯、得來速 | 已定 |                                                                                             |
| 取餐     | 依取餐看板顯示的號碼取餐                                      | 全部               | 已定 |                                                                                             |
| 候位     | 客滿時於門市入口掃描 QR code 取號，依叫號看板入座             | 內用               | 已定 | [biru-api#71](https://github.com/YuanShuoHsu/biru-api/issues/71)（開發中）                  |
| 禁菸     | 室內全面禁菸，入口須設明顯禁菸標示，不得供應與吸菸有關之器物  | 全部               | 已定 | [菸害防制法第 15 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=L0040001&flno=15) |
| 最低消費 | （待定，例：每人低消一份飲品或金額）                          | 內用               | 待定 |                                                                                             |
| 用餐時間 | （待定，例：不限時，或客滿時限 90 分鐘）                      | 內用               | 待定 |                                                                                             |
| 外食     | （待定，例：謝絕外食與外帶飲料）                              | 內用               | 待定 |                                                                                             |
| 寵物     | （待定，例：謝絕寵物，或寵物須裝籠／推車）                    | 內用               | 待定 |                                                                                             |
| 餐具回收 | （待定，例：用餐後放回回收台，或由店員收桌）                  | 內用               | 待定 | [工作動線](layout.md#工作動線)                                                              |
| 插座     | （待定，例：是否提供插座、筆電使用限制）                      | 內用               | 待定 |                                                                                             |
| 兒童     | （待定，例：是否提供兒童座椅、兒童餐具）                      | 內用               | 待定 |                                                                                             |

## 門市差異

目前只有大園店，沒有門市差異。之後有門市規定不同時，在這裡逐條列出門市、項目與規定。
